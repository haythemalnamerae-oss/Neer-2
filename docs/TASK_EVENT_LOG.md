# سجل أحداث المهام — Neer-2

**التاريخ:** 2026-11-13  
**الحالة:** سجل أحداث موحد قائم ومحمي append-only؛ بعض أنواع الأحداث وتدفقات الواجهة ما زالت غير مكتملة.

## الجدول
`public.task_events` يحتوي:
- UUID للسجل ومعرف المؤسسة والمهمة.
- هوية Auth للمنفذ.
- نوع الحدث ووسمه.
- `occurred_at` و`received_at`.
- الإحداثيات والدقة وحالة الموقع.
- `client_event_id` فريد داخل المؤسسة.
- تفاصيل JSON.

## الضمانات
- قيد فريد على `(organization_id, client_event_id)`.
- Trigger يمنع UPDATE وDELETE.
- لا توجد امتيازات UPDATE/DELETE/TRUNCATE لـanon أو authenticated.
- RLS يحدد قراءة الأحداث حسب صلاحية عرض المهمة، والإدخال باسم صاحب الجلسة مع صلاحية تعديل المهمة.
- مفاتيح التكرار لا يجوز إعادة استخدامها لمهمة أو منفذ أو نوع حدث مختلف.
- تمت إضافة إعادة تحقق بعد قفل صف المهمة لتأمين إعادة المحاولة المتزامنة.

## حدود
- لا يوجد بعد hash chain أو توقيع تشفيري مستقل للسجل.
- لا تثبت GPS هوية الشخص أو وجوده القطعي.
- الأحداث غير الميدانية لا تتطلب GPS؛ تسجل `location_status=not_requested`.
