# اختبارات دورة المهام — Neer-2

**التاريخ:** 2026-11-12  
**نوع النتائج:** فحص مصدر ومخطط؛ لم يتم تشغيل بناء أو متصفح أو E2E.

## فحوص تمت

| الفحص | النتيجة |

| RLS على جداول المهام المفحوصة | مفعّل |
| المفاتيح والعلاقات المؤسسية المركبة | موجودة في مخطط التدقيق |
| RPC إنشاء حزمة المهمة | موجود |
| RPC اعتماد/رفض الإنجاز | موجود |
| RPC دورة التنفيذ | موجود |

## مصفوفة اختبار مطلوبة

1. مدير ينشئ مهمة بمكلف ومشاركين وخطوات.
2. موظف ينشئ مقترحًا، ثم مدير آخر يراجعه.
3. منع المنشئ من اعتماد طلبه عندما تكون سياسة maker-checker مفعلة.
4. قبول ورفض مع سبب، والتحقق من التاريخ والإشعار.
5. اختبار حالات التنفيذ: بدء، إيقاف، استئناف، نتيجة، اعتماد.
6. إنشاء مهمتين فرعيتين والتأكد من استقلال الحالة.
7. اختبار ترتيب الخطوات واعتمادياتها بعد تنفيذها.
8. اختبار مستخدم غير عضو ومستخدم مؤسسة أخرى.
9. إرسال مراجعتين متزامنتين والتحقق من وجود قرار واحد فقط.
10. اختبار فشل الشبكة بعد commit والتحقق من عدم تكرار الإنشاء.

لا تسجل أي اختبار على أنه ناجح قبل تشغيله وتوثيق بياناته ونتيجته.
